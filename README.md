# 🫀 IntelliHeart — Heart Disease Prediction System

IntelliHeart is a **Machine Learning–based Heart Disease Prediction System** developed using Python and Flask. The system analyzes clinical and ECG-related health parameters and uses trained Machine Learning models to predict the possibility of heart disease.

The application also includes an integrated **AI-style chatbot** that provides basic information about heart disease, ECG, Machine Learning models, risk factors, and predictions.

## 🚀 Features

* ❤️ Heart disease prediction using Machine Learning
* 🩺 Clinical and ECG parameter analysis
* 🤖 Two trained prediction models
* 📊 Model probability/results
* 📄 Detailed prediction report
* 📥 Downloadable PDF report
* 💬 Integrated Heart Disease chatbot
* 🌐 Flask-based web application
* 📱 Responsive web interface

---

## 🧠 Machine Learning Models

During model development, multiple Machine Learning algorithms were evaluated:

* Logistic Regression
* Decision Tree
* Random Forest
* Support Vector Machine (SVM)
* K-Nearest Neighbors (KNN)
* Gradient Boosting

Based on the evaluation metrics, **Random Forest** was selected as the best-performing model for the final prediction system.

### Evaluation Metrics

The models were evaluated using:

* Accuracy
* Precision
* Recall
* F1 Score
* ROC-AUC
* Confusion Matrix

## 📊 Prediction Models

### Model 1 — ECG + Clinical

Uses ECG and clinical parameters including:

* Age
* Sex
* Chest Pain Type
* Resting Blood Pressure
* Cholesterol
* Fasting Blood Sugar
* Resting ECG
* Maximum Heart Rate
* Exercise-Induced Angina
* Oldpeak
* ST Slope

### Model 2 — Clinical Only

Uses clinical parameters including:

* Age
* Gender
* Height
* Weight
* Blood Pressure
* Diastolic Blood Pressure
* Cholesterol
* Glucose
* Smoking
* Alcohol Consumption
* Physical Activity

The system combines the predictions from both models to generate an overall risk verdict.

## ⚙️ Installation

Clone the repository:

```bash
git clone <your-github-repository-url>
```

Move into the project directory:

```bash
cd heart-prediction-system
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run Locally

Start the Flask application:

```bash
python app.py
```

The application will run at:

```text
http://127.0.0.1:5000
```

Open the URL in your browser to access IntelliHeart.


Make sure `gunicorn` is included in `requirements.txt`.
